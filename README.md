# Poster Generation Competition — Web Portal & Assistant 🎨

An interactive, dark-mode enabled web portal and rulebook system built for the Poster Generation Competition hosted by S.E.S. Polytechnic, Solapur. This repository contains a responsive web interface detailing competition guidelines, format rounds, judging criteria, prize structures, and an embedded interactive chatbot for attendee queries.

- **🎨 Tailwind CSS**: Utility-first CSS styling via CDN with dynamic dark mode and modern animations.
- **⚡ JavaScript (ES6)**: Modern client-side logic handling theme toggling, active section navigation, and the rulebook assistant chatbot.
- **✨ Lucide Icons**: Scalable vector icons for clean UI visuals.

---

## 🚀 Features

- 🧭 **Interactive Rulebook Navigation**: Quick jump links for general guidelines, competition rounds, judging metrics, and awards. 
- 🤖 **Embedded AI Assistant**: Floating interactive widget providing real-time Q&A regarding venue details, allowed equipment, round timings, and event rules.
- 🌙 **Dark/Light Mode Switcher**: Seamless theme toggling with custom styling built on Tailwind CSS.
- 📱 **Responsive Layout**: Designed for mobile, tablet, and desktop viewports with fluid animations and visual feedback.

## 📋 Competition Details

- **📍 Venue**: S.E.S. Polytechnic, 46B, Solapur Bypass Rd, Samrat Chowk, Budhavar Peth, Solapur, Maharashtra 413002.
- **⏳ Format**
  - **Round 1**: 5-minute written prompt prep + 5-minute AI poster generation/rendering.
  - **Round 2**: 5-minute prompt refinement + 5-minute final AI rendering.
- **⚖️ Judging Criteria**: Relevance to Theme, Creativity & Originality, Visual Quality & Composition, and Prompt Efficiency.

## 💻 How to Run

1. Clone or download this repository.
2. Open `rulebook.html` directly in any standard browser. No node installation or local server required!
