# Poster Generation Competition — Web Portal & Assistant 🎨

An interactive, dark-mode enabled web portal and rulebook system built for the Poster Generation Competition hosted by S.E.S. Polytechnic, Solapur[span_1](start_span)[span_1](end_span). This repository contains a responsive web interface detailing competition guidelines, format rounds, judging criteria, prize structures, and an embedded interactive chatbot for attendee queries[span_2](start_span)[span_2](end_span).

## 🚀 Features

- 🧭 **Interactive Rulebook Navigation**: Quick jump links for general guidelines, competition rounds, judging metrics, and awards[span_7](start_span)[span_7](end_span).
- 🤖 **Embedded AI Assistant**: Floating interactive widget providing real-time Q&A regarding venue details, allowed equipment, round timings, and event rules[span_8](start_span)[span_8](end_span).
- 🌙 **Dark/Light Mode Switcher**: Seamless theme toggling with custom styling built on Tailwind CSS[span_9](start_span)[span_9](end_span).
- 📱 **Responsive Layout**: Designed for mobile, tablet, and desktop viewports with fluid animations and visual feedback[span_10](start_span)[span_10](end_span).
